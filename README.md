## 🚀 Milestone: DecodeLabs Virtual Internship (2026)

As part of my continuous learning path, I completed a 4-week project-based cybersecurity internship. Below are the 4 hands-on security tools I built, documented, and deployed during this phase.

### 🔐 1. Password Strength Checker
- Evaluates password entropy and randomness (Shannon entropy).
- Checks against 500+ common passwords (from `rockyou.txt`).
- Generates cryptographically secure passwords using Python's `secrets` module.
- **Tech:** Python

### 🔑 2. Caesar Cipher Encryption/Decryption Tool
- Implements encryption & decryption with a customizable shift key.
- Includes a brute-force mode to demonstrate the weakness of classical ciphers.
- Features frequency analysis to visually show how attackers break substitution ciphers.
- **Tech:** Python

### 🎣 3. Phishing Awareness Analyzer
- Analyzes emails to identify suspicious links, spoofed domains, and cognitive triggers (Urgency, Fear, Authority).
- Provides a risk score (Critical, High, Medium, Low) and actionable triage recommendations.
- **Tech:** Python

### 🛡️ 4. Windows System Vulnerability Scanner
- Automates Blue Team security audits for Windows 11.
- Checks Firewall status, BitLocker encryption, Admin group memberships, Guest account status, Windows Updates, and Screen Lock timeout.
- Generates a professional Markdown report with remediation steps.
- **Tech:** Python + PowerShell
